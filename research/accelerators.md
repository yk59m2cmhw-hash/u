# Акселераторы и программы, которые открывают крупные кредиты

Данные — в [accelerators.csv](accelerators.csv). Проверено через веб-поиск 11.11.2026; даты следующих наборов —
**оценка** по прошлым годам: как только набор открыт, правьте CSV.

## Зачем они вам

Крупные тиры кредитов (Google AI до $350K, AWS Portfolio до $100–200K, Microsoft Investor Offer до $150K)
выдают стартапам с институциональным инвестором или из акселератора-партнёра. Поэтому акселератор — не
отдельная цель, а ключ к фазе P3 базы кредитов.

## Что реально для команды «только идея»

| Шанс | Программа | Почему |
|---|---|---|
| высокий | **NVIDIA Inception** | бесплатно, без отбора по стадии: нужны юрлицо, сайт и разработчик. Подавать сразу после регистрации |
| средний | **Antler** | принимает людей и команды на стадии идеи; инвестиция решается во время резиденции ($100–250K в зависимости от города) |
| средний | Региональные технопарки: Astana Hub, IT Park Uzbekistan, инкубаторы Startup India | ниже конкуренция, налоговые льготы, локальные гранты |
| средний | Founder Institute | платная part-time программа для стадии идеи; мало денег, но даёт структуру и сеть |
| низкий | Entrepreneur First | берёт сильных людей до команды и идеи; очень высокий отбор |
| низкий | Google for Startups Accelerator, AWS Generative AI Accelerator | нужны продукт и traction; это цель фазы 4, а не фазы 0 |
| низкий | Y Combinator, Techstars | без traction шансы малы; подавать в каждый набор, когда появятся первые платящие клиенты |

## Условия крупных программ

| Программа | Деньги | Доля | Кредиты |
|---|---|---|---|
| Y Combinator | $500K | 7 % за $125K (post-money SAFE) + $375K на uncapped MFN SAFE | партнёрские перки |
| Techstars | $220K | $20K за 5 % + $200K uncapped MFN SAFE | партнёрские перки |
| Antler | $100–250K, по городу | например, США — $250K за 9 % | перки |
| Entrepreneur First | до $250K | около 8 % | перки, стипендия без доли |
| Google for Startups Accelerator | — | без доли | Google Cloud кредиты по заявке |
| AWS Generative AI Accelerator | — | без доли | до $1M кредитов AWS |

## Как использовать

1. Сразу после регистрации — NVIDIA Inception (действие Мандалы 3.1).
2. Параллельно с MVP — Antler или региональный технопарк в вашей стране.
3. Когда появятся 3–5 платящих клиентов — YC, Techstars, Google и AWS accelerators (3.2–3.4).
4. Любой из пунктов 2–3 с инвестицией открывает фазу P3 базы кредитов.
