## Цель этапа

Технический MVP, который можно развернуть за час после получения кредитов.

## Пункты

4.1 **Инференс** → `serving/`: docker-compose с vLLM (OpenAI-совместимый API) для двух профилей — малая модель
    на L4 24 GB и средняя на A100 или H100 80 GB; шлюз LiteLLM перед своими моделями и API-моделями (ключи
    только через env); маршрутизация «дешёвая модель → сильная для сложных задач»; ключи клиентов; учёт токенов
    по клиенту (SQLite); лимиты. `serving/README.md`.

4.2 **Облако как код** → `infra/terraform/gcp` и `infra/terraform/aws`: GPU-VM (L4, g6) со стартовым скриптом
    vLLM, firewall, бюджеты и алерты, авто-выключение при простое, переменные для региона и квот.
    `terraform fmt` и `terraform validate`, если terraform удаётся поставить; реального деплоя нет.

4.3 **Агент** → `agents/`: сервис на Python (FastAPI) для ниши из `strategy/DECISION.md`. Один агент — один
    процесс; инструменты (календарь, CRM через webhook, таблица); каналы (Telegram-бот и веб-виджет);
    передача человеку при неуверенности; журнал действий; конфиг на клиента (мульти-тенантность); LLM через
    шлюз из 4.1 (OpenAI-совместимый клиент). Тесты на pytest с мок-LLM и eval-набор из 20 диалогов в
    `agents/evals/` — запусти.

4.4 **Runbook** → `docs/runbook.md`: как развернуть всё за час, когда придут кредиты; безопасность; контроль
    расходов.

4.5 **CI** → `.github/workflows/ci.yml`: тесты Python (`tools/`, `models/`, `agents/`) на каждый push.

Бонус, если остаётся лимит: `Dockerfile` для `agents/`, демо-скрипт диалога, оценка стоимости MVP в месяц на
разных облаках (`docs/mvp-cost.md`); в `mandala/mandala.json` поставь `ready` для 2.6, 5.1, 5.2, 5.3, 5.6, 5.8,
7.1, 7.4, 7.8 и пересобери `python3 mandala/build.py`.
