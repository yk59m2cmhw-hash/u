## Правила этого этапа

Те же, что на этапе 3 (`plan/stages/STAGE-3.md`, раздел «Правила»): коммит после каждого пункта, запись
решений в журнал, Казахстан — гипотеза рынка, никаких секретов в репозитории (только `.env.example`), тесты

## Цель этапа

Всё, чтобы подключить первую компанию к пилоту за один день после её согласия.

## Пункты

4.1 **Каналы** → `okno/channels/`: решение о WhatsApp (официальный WhatsApp Business Platform напрямую через
    Meta Cloud API или через сервис-посредника; неофициальные API — отклонить: нарушают правила WhatsApp и
    ведут к блокировке номера) с записью в журнале; адаптер вебхуков Meta Cloud API (проверка подписи,
    входящий текст, ответ) и адаптер Telegram-бота. Тесты на записанных примерах запросов, без реальных токенов.

4.2 **Передача заявок** → вебхук общего вида, Telegram-чат сотрудников, адаптеры для Bitrix24 и amoCRM
    (популярны в Казахстане — проверить) на уровне входящих вебхуков, с документацией.

4.3 **Кабинет владельца** → простая страница: редактировать базу знаний (услуги, районы, часы, вопросы и
    ответы), смотреть и выгружать заявки; доступ по токену.

4.4 **Развёртывание и данные** → `Dockerfile`, `docker-compose.yml`, `docs/deploy.md` (дешёвый сервер; вариант
    с размещением в Казахстане), резервные копии. Запись в журнал о хостинге с учётом закона Казахстана о
    персональных данных (требования к месту хранения, трансграничная передача в API модели, согласие
    клиентов) — с пометкой «проверить у юриста»; тексты уведомления и согласия для пилота.

4.5 **Качество** → набор диалогов до 40, включая трудные случаи (давят на цену, грубят, пишут не по теме, на
    казахском и вперемешку, аварии); регрессионные тесты; `.github/workflows/ci.yml` — тесты на каждый push.

4.6 **Решение о юрисдикции** → `company/jurisdiction-decision.md`: критерии, варианты (из
    `research/jurisdictions.md`), рекомендация в зависимости от фактов о гражданстве и резидентстве основателей
    и список этих фактов. Только законные пути; «проверить у юриста». Запись в журнале решений.

4.7 **Кредиты под архитектуру «готовый API»** → обновить `research/credits/calendar.md` и
    `research/credits/README.md`: какие программы покрывают выбранные API (Gemini через Google Cloud, Claude
    через AWS Bedrock или Google Vertex AI, Azure), и строку «экономия, если одобрят» в
    `models/okno_costs.py`.

Бонус, если остаётся лимит: чек-лист подключения компании к пилоту за один день (`gtm/pilots/onboarding.md`);
в Мандале — `ready` для новых заготовок, затем `python3 mandala/build.py`.
