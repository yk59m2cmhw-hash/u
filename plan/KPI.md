# Метрики еженедельного отчёта

Отчёт пишется каждое воскресенье на ретро (действие Мандалы 4.2), одной таблицей. Цели — для базового плана
из [strategy/business-model.md](../strategy/business-model.md); после первых 10 интервью их стоит
пересмотреть.

## Главная метрика

**Записи, которые сделали наши агенты за неделю, по всем клиникам.** Она растёт, только если растут и
клиенты, и польза для каждого из них.

## Формат записи

```text
Неделя N (даты)
Главная метрика: X записей (было Y)
Сделано: действия Мандалы 1.1, 2.2, 6.2
Цифры: интервью A, пилоты B, платящих C, MRR $D
Что не получилось и почему:
План на следующую неделю (3–5 действий):
```
