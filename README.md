# AI-стартап на облачных кредитах — штаб

Здесь всё по проекту: разбор идеи, Мандала из 81 клетки, большие шаги и результаты облачных этапов. Каждый
этап сам коммитит и пушит сюда свой результат.

## Вердикт в пяти строках

1. «Набрать кредитов → запустить open-source модели → продавать токены» как бизнес не работает: токены — самый
   дешёвый слой рынка, GPU у гиперскейлеров в 2–3 раза дороже, чем у GPU-облаков, кредиты сгорают за 1–2 года.
2. Работает перевёрнутая версия: **кредиты — топливо, а продукт — AI-агенты, которые делают конкретную работу
   для бизнеса в одной нише.**
3. Свои модели — там, где они дают преимущество: приватность данных, локальный язык, цена на больших объёмах.
4. Крупные кредиты ($100K+ у одного провайдера) открываются после юрлица и инвестора или акселератора; без них
   реально $5–25K.
5. Оценка провала: 95–98 % для «токенов на кредитах», 65–80 % для «агентов под нишу». Финансовый риск — сотни
   долларов, главная ставка — время.
