# Метрики пилота

Одна таблица на каждый пилот, заполняется раз в неделю. Пороги — из [плана проверки готовности
платить](../wtp-test-plan.md), гипотеза H5.

| Метрика | Как считать | Порог успеха |
|---|---|---|
| Обращений за неделю | разговоров в канале Okno | для понимания объёма |
| Ответ быстрее минуты | доля разговоров, где первый ответ пришёл < 60 секунд | ≥ 70 % |
| Полная заявка | доля разговоров, закончившихся карточкой с задачей, районом, временем и телефоном | ≥ 50 % |
| Переспросы | доля карточек, по которым сотрудник переспросил данные из карточки | < 30 % |
| Передано человеку | доля разговоров со статусом «нужен сотрудник» (аварии, жалобы, вне базы знаний) | для настройки; рост выше 30 % — пересмотреть базу знаний |
| Ошибки агента | названная цена, обещанный выезд, неверная информация | 0 цен и 0 обещаний выезда; остальное — исправить в течение дня |
| Заказы из заявок | сколько заявок компания превратила в заказ (со слов компании) | для расчёта окупаемости |
| Оценка владельца | «насколько вам было бы жаль отключить Okno?» от 1 до 5 | ≥ 4 |
